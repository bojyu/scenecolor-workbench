## 目标与基线

本计划用于扩展规则、校准集和评测，不代表微调模型权重。当前基线有 19 张场景：脚垫伸出 6、收起 8、未知 5；`partial` 与确认无脚垫的 `absent` 均为 0；11 张可自动处理、7 张需复核、1 张多椅子不匹配。

解决两个已确认问题：

1. 脚垫伸出、收起、遮挡或裁出画面时，状态必须独立于角度判断。
2. 半椅和特写不按可见面积判断，而按关键结构是否可观测；证据不足时输出粗方向或主动放弃，不强制猜精确角度。

## 计划中的标签结构

在下一版校准数据中增加以下字段，完成评测后再替换当前生产结构：

```json
{
  "cropType": "upper_half",
  "visibleParts": {
    "backrest": "full",
    "seat": "partial",
    "leftArmrest": "full",
    "rightArmrest": "hidden",
    "base": "hidden",
    "footrestPad": "hidden",
    "rails": "hidden"
  },
  "angleObservability": "coarse",
  "coarseDirection": "right",
  "angle": "unknown",
  "azimuth": null,
  "footrest": { "state": "unknown", "visibility": 0 },
  "reviewReasons": ["single_side_geometry", "footrest_outside_crop"]
}
```

- 可见部件值：`full`、`partial`、`hidden`。
- `angleObservability`：`exact`、`coarse`、`none`。
- `coarseDirection`：`front`、`right`、`back`、`left`、`unknown`；左右沿用画面朝向约定，即椅子前方/座面轴投向画面右侧为 `right`，投向画面左侧为 `left`。
- 裁切后不可见的属性必须重新标为 `unknown`，禁止继承完整原图的隐藏状态。

## 数据集目标

新增 120 张困难样本，保留原 19 张作为回归集：

| 样本来源或构图 | 数量 | 主要训练目标 |
| --- | ---: | --- |
| 完整或近完整椅子 | 30 | 八方向与脚垫状态对照 |
| 上半椅、椅背与扶手 | 25 | 正面、左右粗方向与不可见脚垫 |
| 下半椅、坐垫与脚垫 | 25 | 脚垫状态与角度降级 |
| 单扶手、侧边、功能特写 | 20 | `coarse`/`none` 边界 |
| 人物、桌面、叠图、暗光遮挡 | 20 | 主动放弃与复核触发 |

来源比例：至少 60 张真实场景、最多 40 张由已标注完整图生成的受控裁切、20 张视觉相似但真实角度不同的困难负例。近重复图必须放在同一数据分区，避免测试泄漏。

脚垫覆盖目标：伸出不少于 25、收起不少于 25、`partial` 不少于 12、不可观测不少于 30、确认无脚垫能力不少于 8。其余样本用于补齐遮挡和边界情况。

## 执行阶段

1. **冻结基线**：保存当前 19 张标签、文件哈希和现有评测结果。
2. **重标当前案例**：为 19 张图补充裁切类型、可见部件、角度可观测性和复核原因。
3. **建立困难集**：按上表收集 120 张；受控裁切不得继承已经裁掉的角度或脚垫标签。
4. **双遍标注**：第一遍独立标注，第二遍只复核冲突项；保留原图证据句，不以人物朝向代替椅子几何。
5. **拆分数据**：80 张规则/示例集、20 张验证集、20 张盲测集；原 19 张始终作为独立回归集。
6. **更新规则**：新增可见性规则；只有至少两项独立角度证据时才允许 `exact`，脚垫只依据垫板和导轨物理连续性。
7. **扩展评测脚本**：增加可观测性、粗方向、未知召回率和危险自动匹配统计。
8. **工作台盲测**：先运行盲测集，再运行原 19 张；未通过阈值时只输出报告，不替换现有生产规则。

## 每轮训练后的工作台验收

每轮执行结束后必须遵循 `workbench-validation.md`：打开实际项目页面、加载离线 Skill 成果、核对自动/复核/拦截案例，并发送总览、自动匹配和安全案例三张截图。脚本评测通过但缺少工作台截图时，本轮状态仍为未完成。

## 自动匹配门槛

- `exact` 角度且角度置信度不低于 0.85，脚垫状态明确且可见度不低于 0.5：允许自动匹配。
- `coarse` 角度但脚垫明确：只给候选素材，状态为 `review`。
- 角度明确但脚垫不可观测：禁止跨脚垫状态自动选择。
- 只有单扶手、人物方向或功能箭头：不得输出精确角度。
- 多椅子不同角度、角度 `none` 或脚垫 `unknown`：保持 `unmatched`，不得循环调用模型强制出答案。

## 必须通过的回归案例

- `004-2.png`：右向粗方向；精确角度未知；脚垫未知；复核或不匹配。
- `005-2.png`：左向粗方向；脚垫伸出；仅提供镜像/角度复核候选。
- `PC003-1.png`：左向粗方向；脚垫未知；禁止自动选脚垫状态素材。
- `PC004.jpg`：正面角度可确定；脚垫未知；角度结果不能掩盖脚垫不可观测。
- `007.png`：多椅子且角度不同；始终不自动匹配。

## 验收指标

- `exact` 可观测样本的八方向准确率不低于 90%。
- `coarse` 样本的四方向准确率不低于 95%。
- 明确可见脚垫样本的状态准确率不低于 95%，伸出召回率不低于 95%。
- 不可观测属性的 `unknown` 召回率不低于 95%。
- `unknown`、`none` 或多椅子场景的危险自动匹配数必须为 0。
- 错误标记为伸出的比例不高于 2%，镜像素材必须 100% 标记 `review`。
- 原 19 张的角度、脚垫和安全门禁不得低于当前基线。

## 调用与成本约束

- 一轮只做一次批量识别和一次冲突复核；不得对同图自动重试。
- 输入图最长边预处理到 1024 像素，原图只用于人工复核。
- 复用现有 56 张素材锚点，不重新扫描 459 张素材。
- 使用付费 API 前必须得到明确同意，并为单轮设置调用数与 Token 硬上限。
- 匹配阶段保持本地确定性执行，不让 Agent 逐颜色重复判断。
