# 每轮训练后的工作台验收

在角度规则、脚垫规则、可见性规则、校准标签、素材索引、匹配脚本或评测脚本发生变化后执行本流程。缺少工作台实测、指标或截图时，不得声明训练完成。

## 验收顺序

1. 运行 Skill 结构校验和项目完整检查；任何失败都先修复。
2. 重新生成本轮预测、匹配结果与评测报告，记录文件哈希或训练轮次。
3. 复用已运行的工作台；若服务未启动，再启动项目并确认本地页面可访问。
4. 在工作台点击离线 Skill 成果入口，禁止使用演示假数据或只检查 JSON。
5. 核对页面汇总数量、角度标签、脚垫状态、自动/复核/拦截数和外部调用数。
6. 检查至少一个自动匹配、一个复核或镜像匹配、一个未知/多椅子安全拦截案例。
7. 对照实际场景图与选中的图2文件名；错误素材即判定本轮失败。
8. 保留工作台成果标签页，并在最终回复中发送截图和指标结论。

## 必须截取的画面

- `workbench-overview.png`：包含训练轮次、场景数、伸出/收起/未知数、自动/复核/拦截数和 Token/外部调用数。
- `workbench-auto-match.png`：包含完整场景图、角度、脚垫状态、至少一组图2缩略图和匹配状态标签。
- `workbench-safety-case.png`：包含镜像复核、脚垫未知、角度不可观测或多椅子拦截中的至少一种。

将截图与本轮报告放在 `.scenecolor/skill-training/runs/<轮次>/`。最终回复必须使用绝对路径内嵌截图，不能只提供文件名或口头说明。

## 页面验收条件

- 页面汇总与评测 JSON 数量完全一致。
- 自动匹配案例显示同脚垫状态素材，禁止伸出与收起交叉。
- 镜像候选明确显示 `review` 或“镜像复核”。
- `unknown`、角度 `none` 或多椅子场景不自动选素材。
- 页面显示的外部调用数和 Token 与本轮实际记录一致。
- 页面无加载错误、空白缩略图、重复选择或旧轮次缓存污染。

## 失败处理

- 任一安全门禁失败：保留旧生产规则，只输出失败报告和截图。
- 指标文件与页面不一致：清除本轮页面缓存后只重载一次；仍不一致则停止。
- 页面加载失败：修复工作台接入后重新执行整套验收，不用脚本自测替代。
- 需要付费 API 才能继续：先报告预计调用数和 Token，得到明确同意后再执行。

## 最终报告格式

报告训练轮次、数据集规模、角度准确率、脚垫准确率、联合准确率、未知召回率、自动/复核/拦截数、危险自动匹配数、外部调用数、Token、通过/失败结论和三张截图。明确区分“模型判断错误”“证据不可观测”和“素材库没有兼容锚点”。
